# Интернет-магазин (ООП)

## Описание проекта

Данный проект представляет собой ядро интернет-магазина, реализованное с использованием объектно-ориентированного программирования (ООП) на Python.

## Реализованный функционал

### Класс `Product` (Товар)
- Хранит информацию о товаре:
  - `name` — название товара
  - `description` — описание товара
  - `price` — цена товара
  - `quantity` — количество на складе

### Класс `Category` (Категория)
- Хранит информацию о категории товаров:
  - `name` — название категории
  - `description` — описание категории
  - `products` — список товаров в категории
- Атрибуты класса:
  - `category_count` — общее количество созданных категорий
  - `product_count` — общее количество товаров во всех категориях
