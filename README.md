# Интернет-магазин (ООП)

## Описание проекта

Данный проект представляет собой ядро интернет-магазина, реализованное с использованием объектно-ориентированного программирования (ООП) на Python.

## Реализованный функционал

### Класс `Product` (Товар)
- Хранит информацию о товаре:
  - `name` — название товара
  - `description` — описание товара
  - `price` — цена товара (приватный атрибут с геттером и сеттером)
  - `quantity` — количество на складе
- Методы:
  - `__str__` — строковое представление
  - `__add__` — сложение товаров одного класса
  - `new_product` — класс-метод для создания из словаря

### Абстрактный класс `BaseProduct` (Базовый продукт)
- Родительский класс для всех продуктов
- Содержит общую функциональность:
  - Атрибуты: `name`, `description`, `__price`, `quantity`
  - Геттер и сеттер для `price`
  - Абстрактные методы: `__str__`, `__add__`
- Классы `Product`, `Smartphone`, `LawnGrass` — наследники `BaseProduct`

### Класс-миксин `ReprMixin`

Класс-миксин `ReprMixin` при создании любого объекта автоматически печатает в консоль информацию о том, от какого класса и с какими параметрами был создан объект.

**Пример вывода:**
```
Product('Продукт1', 'Описание продукта', 1200, 10)
Smartphone('iPhone 15', 'Флагман', 100000.0, 5, 3.5, '15 Pro', 256, 'Black')
LawnGrass('Газон', 'Трава', 500.0, 100, 'Россия', '14 дней', 'Зеленый')
```

**Особенности:**
- Миксин добавлен в цепочку наследования класса `Product` **первым** (`class Product(ReprMixin, BaseProduct)`)
- Использует `super()` для вызова родительского конструктора
- Работает для всех наследников: `Product`, `Smartphone`, `LawnGrass`

**Расположение:** `src/mixin.py`

### Класс `Category` (Категория)
- Хранит информацию о категории товаров:
  - `name` — название категории
  - `description` — описание категории
  - `__products` — приватный список товаров
- Атрибуты класса:
  - `category_count` — общее количество созданных категорий
  - `product_count` — общее количество товаров во всех категориях
- Методы:
  - `add_product` — добавление товара (только Product и наследники)
  - `average_price` — средняя цена товаров
  - `products` — геттер списка товаров (строка)
  - `__str__` — строковое представление

### Обработка исключений

- **Нулевое количество:** При создании товара с `quantity=0` или меньше выбрасывается `ValueError` с сообщением:
  ```
  Товар с нулевым количеством не может быть добавлен
  ```
- **Метод `average_price`:** возвращает средний ценник всех товаров в категории.
  - Складывает **только цены** всех товаров и делит на их количество
  - Если в категории нет товаров — возвращает `0` (обработка `ZeroDivisionError` через `try/except`)

### Классы-наследники

#### Класс `Smartphone` (Смартфон) — наследник `Product`
- Дополнительные атрибуты:
  - `efficiency` — производительность
  - `model` — модель
  - `memory` — объем встроенной памяти (ГБ)
  - `color` — цвет

#### Класс `LawnGrass` (Газонная трава) — наследник `Product`
- Дополнительные атрибуты:
  - `country` — страна-производитель
  - `germination_period` — срок прорастания
  - `color` — цвет

### Ограничения

- **Сложение (`__add__`)**: можно складывать только товары **одного класса**. При попытке сложить разные классы (например, `Smartphone` и `LawnGrass`) выбрасывается `TypeError`.
- **Добавление в категорию (`add_product`)**: можно добавлять только объекты класса `Product` или его наследников. При попытке добавить другой объект (строку, число) выбрасывается `TypeError`.
## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone <url-репозитория>
```

2. Установите зависимости:
```bash
poetry install
```

3. Запустите основной файл:
```bash
python main.py
```

## Запуск тестов

```bash
poetry run pytest tests/ -v
```
